Grade Genius
Student Management and Communication Platform

Grade Genius is a web-based student management platform designed to help schools manage learner information and improve communication between learners and teachers.

The system provides a central platform where users can register, log in, manage student information, and communicate through a built-in chat system.

Features
User registration and login
Student information management
Teacher and learner accounts
Student dashboard
Teacher–learner communication
Real-time-style chat interface
Student records management
Responsive web interface
MySQL database integration
Backend API using Node.js and Express
